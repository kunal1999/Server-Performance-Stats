# Server Performance Stats

This project contains a Bash script that reports basic server performance statistics, including:

- Total CPU usage
- Total memory usage
- Total disk usage
- Top 5 processes by CPU usage
- Top 5 processes by memory usage

## Run the project

Open a terminal in the project folder and run:

```bash
chmod +x server-stats.sh
./server-stats.sh
```

You can also run it explicitly with Bash:

```bash
bash ./server-stats.sh
```

## Windows setup

Because this is a Bash script, use either WSL or Git Bash on Windows.

### With WSL

```powershell
wsl
cd /mnt/c/Users/kunal/OneDrive/Documents/project/Server-Performance-Stats
bash ./server-stats.sh
```

### With Git Bash

```bash
cd "C:/Users/kunal/OneDrive/Documents/project/Server-Performance-Stats"
bash ./server-stats.sh
```
